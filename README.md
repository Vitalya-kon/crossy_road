Захватывающая 3D аркадная игра в браузере! Управляйте одним из четырёх уникальных животных, переходите бесконечные дороги, избегайте машин и устанавливайте рекорды.

![Gameplay Screenshot](assets/screenshot.png)

## 🚀 Демо

**Играть прямо сейчас:** [vitalya-kon.github.io/crossy_road](https://vitalya-kon.github.io/crossy_road/)

## ✨ Особенности

### 🎯 Геймплей
- **Бесконечный режим** с процедурной генерацией уровней
- **4 уникальных персонажа**: Жираф 🦒, Лев 🦁, Зебра 🦓, Бегемот 🦛
- **Система подсчёта очков** с сохранением рекорда в localStorage
- **Разнообразные препятствия**: машины, грузовики, деревья

### 🎨 Графика и звук
- **3D-графика** на базе Three.js с системой теней и освещения
- **Изометрическая камера** для оптимального обзора
- **Полноценная звуковая система**:
  - Фоновая музыка
  - Звуки прыжков
  - Звуки трафика
  - Звук окончания игры
- **Управление звуком** (включение/выключение)

### 📱 Кроссплатформенность
- **ПК**: управление стрелками клавиатуры
- **Мобильные устройства**: сенсорные кнопки на экране
- **ТВ-устройства**: поддержка Яндекс.Игры SDK
- **Адаптивный дизайн** для любых размеров экранов

## 🎮 Управление

### Клавиатура (ПК)
- **↑** - Движение вперёд
- **↓** - Движение назад
- **←** - Движение влево
- **→** - Движение вправо

### Сенсорное управление (мобильные)
Используйте экранные кнопки для движения в четырёх направлениях.
